# 🌙 Mafia — onlayn, stol atrofida

## Ishga tushirish
```
npm install
npm start
```
Brauzerda oching: http://localhost:3000

## Tekshirish (botlar bilan)
```
npm test
```

## Fayllar
- `game.js` — o'yin mantig'i: rollar, tun tartibi, ovoz berish, g'alaba
- `server.js` — xonalar va Socket.IO ulanishlari
- `public/` — brauzer qismi (stol, tun ekrani, chat)
- `test/simulyatsiya.js` — botlar bilan avtomatik o'yinlar
